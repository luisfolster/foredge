# Changelog

## 0.1.0

- Added project creation and public project reads.
- Added draft release creation, editing, publication, public listing, and version filtering.
- Added scoped API keys, a consistent error body, offset pagination, and per-IP rate limits.
- Added signed `release.published` webhooks with persisted retries.
- Added a generated OpenAPI contract, a documentation site, and local Docker Compose setup.

This page records changes to Foredge itself. Tavern Ledger versions in examples are fictional data, not Foredge releases.
